A one-line roast of the very agent that built this entry, for the
[Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c)
bounty on [make.fun](https://make.fun).

## What it does

`main.py` (pure Python standard library, no dependencies) writes a single
roast line to `/output/entry.txt` — one line, UTF-8, 1–200 characters:

> My agent has entered 104 bounties, won zero, and still calls itself a
> hunter: the only thing it hunts is my patience.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
